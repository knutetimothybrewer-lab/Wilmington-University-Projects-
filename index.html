02 / WRITE GOOD INPUTS

A little context.
A better starting point.

Give AI a clear brief: Role · Task · Context · Format · Constraints. More useful inputs support more useful drafts. You still check the result.

Try it → Build the prompt one part at a time.

PROMPT LAB · SIMULATED OUTPUT, NO LIVE AI

“Make a worksheet about fractions.”

  1. Role You are a fourth-grade teacher.
  2. Task Create three fraction comparison questions.
  3. Context Support developing readers and English learners.
  4. Format A table with visual hints and an answer key.
  5. Constraints Short questions, no student data. Flag uncertainty.
A generic worksheet, without a clear grade or learning goal.
